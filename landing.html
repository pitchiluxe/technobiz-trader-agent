Builder

Erick Omari

Founder · Quant Developer

Erick built TechnobizTrader to remove the part of trading that loses money — discretionary override at the worst possible moment. The system encodes Michael S.'s ICT playbook into a deterministic three-agent pipeline so the only question that matters is whether the structure is there, not whether the trader is awake.

The codebase spans a Python multi-agent runtime, a FastAPI control plane, an Electron-style trading office UI, and a PyInstaller-packaged Windows installer — all wired to MetaTrader 5 with full audit logging and risk-mandated hard stops.
